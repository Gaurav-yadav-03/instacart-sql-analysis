# Instacart SQL Customer Behavior Analysis

This project analyzes the Instacart grocery dataset using SQL to understand customer purchasing behavior, product popularity, basket size patterns, and churn trends.

## Tools Used
SQL (MySQL)

## Analysis Performed
• Customer order analysis  
• Basket size analysis  
• Top product analysis  
• Reorder behavior  
• Market basket analysis  
• Customer segmentation  
• Customer churn analysis  

## Dataset
Instacart Market Basket Analysis Dataset  
Source: Kaggle

## Key Insights
• A small number of products account for a large share of orders  
• Certain product pairs are frequently purchased together  
• Customer activity varies significantly across segments  
• Some customers show signs of churn after long inactivity
